# Android 学习通助手交付修正

用户于 2026-10-10 指定最终交付物为手机端应用。沿用已有 Android 包名和签名，交付可安装 APK。默认按 Android 独立运行实现；此前 Windows 外壳保留为已有成果。

## 手机端闭环

- 首页：登录状态、通知监听状态、手机本地消息和待确认任务数量。
- 学习通登录：应用内 WebView 打开学习通官方 HTTPS 页面，使用官方二维码；同手机二维码需另一屏幕协助扫描。登录页保留官方额外验证功能，不自行收集密码。
- 读取：在学习通页面打开期间定时读取已渲染聊天文字、课程通知正文；复用已验证的 DOM 解析器。跨域 iframe 不能直接读取时提示打开对应入口，不将空内容报为成功。
- 后台：沿用获用户授权的 NotificationListenerService，将学习通系统通知原文直接保存到手机。本机查看消息、识别任务和确认任务无需电脑。
- 本地消息：保存原文、发布时间、接收时间、来源，重复来源幂等；未知发布时间不生成相对日期。
- 本地任务：规则识别作业、实验、考试和阅读/讨论准备，先生成待确认草稿；确认后查看待办，手动记录完成/提交，逾期状态自动标红。
- 账号退出：清除本应用 WebView 会话，保留原文、任务和旧电脑配对数据。
- 旧版电脑伴侣移到“更多 → 连接电脑”，保留原队列及配对流程。

## 边界

网页读取仅在应用打开该页面期间进行；后台系统通知只包含学习通实际发布给 Android 的文字，可能是摘要。不能承诺后台持续遍历完整学习通历史或平台原生回执。真实 Android WebView 的扫码、会话持久化和后台通知到达需手机验收。

## 验证和产物

新增纯 JVM 行为测试覆盖本地存储恢复、去重、草稿确认、未知日期、逾期日期边界和官方 URL 限制；Node/Edge fixture 覆盖手机网页读取脚本。离线构建 APK，验证签名与旧版本一致，保存产物哈希，提供安装说明。无真机/模拟器时明确标注原生扫码验收未完成。
