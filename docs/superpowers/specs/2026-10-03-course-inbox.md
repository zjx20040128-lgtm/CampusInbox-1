# CourseInbox 基础版规格

在 D:\Doc\course-inbox 新建独立项目，默认本地运行，无平台账号和云端依赖。
基础闭环：文本/截图导入 → 提取任务草稿 → 核对原文与字段 → 确认新增/延期/取消 → 待办与截止提醒 → 日历导出。

规则模式明确标注；可选 Ollama/OpenAI-compatible 模型通过受限工具调用读取任务、提交草稿。模型不能直接写任务，不能扩大当前课程/班级范围，最多 8 次工具调用，展示轨迹。
持久化消息、草稿、任务、来源及历史；重复上传幂等；仅课程、班级和任务标识一致时提出合并。变更需人工确认，使用版本校验。日期不明确时留空，不擅自补 23:59，相对日期以消息发布时间为基准。
状态区分待开始、进行中、已做完、已提交、已取消。已做完仍提示提交，统计不推断平台提交结果。

提供带令牌和来源白名单的 Android 通知接收接口，配套原生 NotificationListenerService 工程。手机排队，用户启动或新通知时重试。不承诺操作系统唤醒期间的可靠后台定时上传、应用内全文、历史、所有通知或 iOS 全局监听。
截图使用 Windows 自带 OCR；不可用时说明并支持粘贴文本。PDF 文本提取为可选依赖。
界面中文且支持移动端；示例明确标注并需显式加载。交付启动脚本、README、API、样例、Docker 文件、自动测试。
默认监听 127.0.0.1；局域网需显式切换 host 并使用令牌，不自动改防火墙。密钥不进前端源码、模型上下文、Git 或日志。
