# 网页识别评测

用户要求将已有电脑端评测可视化，直接在当前本地网页集成，不创建独立站点或发布任何数据。

## 设计

左侧“连接与工具”增加“识别评测”。结果页提供数据集选择、规则评测、本机模型选择与对比、进度/停止、历史结果、中文指标解释、准确率与耗时图以及逐条统计。标注页将原文和结构化任务编辑放在一起，支持普通通知、多个任务、未知截止、延期/取消，明确保存并核对后才参与评测。

后端复用既有评测核心；规则/模型同轮用同一份只读SQLite与标签快照。后台只允许一项评测，支持取消，不阻塞普通任务和同步API。标签文件仅允许现有数据目录内的JSON，保存用内容版本防止多标签页覆盖，原始消息与已确认任务不修改。所有评测入口必须本机主令牌授权；报告只包含哈希与指标。模型仅允许已安装的本机Ollama，不下载、不改配置。
