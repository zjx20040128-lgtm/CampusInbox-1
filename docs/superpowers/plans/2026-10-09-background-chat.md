# 学习通后台聊天同步修复

用户授权首次在本软件扫码，之后自动读取消息，不依赖手机伴侣或手动打开学习通网页。此授权包含后台切换会话；2026-10-06 浏览器组件仅支持当前会话的限制不适用于此功能。

- 复用软件专用浏览器与 Windows 加密会话，通过官方聊天页面可见节点读取会话文字。
- 聊天与课程通知分别定时检查，单个入口或旧通知失败不阻塞另一个入口。
- 所有非空文字先保存消息记录；数字、符号保留，任务规则只生成待确认草稿。
- 使用平台消息编号去重。暂停和旧进程的回传仍受会话代次保护。
- 分别显示聊天与课程通知的同步状态，聊天加载失败不能被通知成功掩盖。
- 软件验收使用临时数据库及清理后的模拟官方页面；真实账号只核对本次用户指出的会话。不得将截图转录当作后台采集证据。
- 不发送聊天、不自动确认任务，不采集图片、音视频或未加载的完整历史。

验收：短消息与符号留存、任务草稿、关闭前台仍捕获新聊天、多会话轮询、暂停、恢复去重、聊天故障时课程通知可继续及状态可见。
