# 手机竖屏登录 UI · 0.3.1

日期：2026-10-10。用户提供旧手机登录截图并确认局部改版：保留官方白色卡片与蓝色风格，扫码/账号切换，较大二维码和输入区，说明收起，认证后再显示消息入口。

## 实现

- 应用内顶部保留返回、连接学习通、官方域名和状态；长说明放入右上角“说明”。
- 官方已知登录页增加“扫码登录 / 账号登录”两个切换入口。去掉 900px 桌面双栏的绝对定位和垂直居中，手机单栏卡片最大 420px。
- 扫码区约 240px；账号输入和登录按钮至少 52px 高。官方表单和输入节点没有被克隆或替换，没有读取输入值、自动接受协议或改变提交处理器。
- 官方协议在两种模式都保持可见；官方过期二维码遮罩、刷新处理器、扫码待确认状态保留。新增刷新按钮调用原官方“重新获取”入口。
- 只在官方 passport2.chaoxing.com 的已知 /login 页面、找到完整原控件时适配。未知结构或缺失布局资源保持官方原版缩放。右上角“说明”可双向切换手机布局与官方原版，切换会重载页面并可能丢失未提交输入。
- 显式认证证据出现后才展示聊天/通知入口。读取异常返回 error/authenticated:false，不再以 partial 冒充认证会话。

官方结构来自当天全新匿名会话的[学习通登录页](https://passport2.chaoxing.com/login?fid=&newversion=true&refer=https://i.chaoxing.com)，没有访问现有账号、填写真实凭据或提交登录。
