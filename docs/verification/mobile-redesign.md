# 手机连接页面精简：0.2.5

日期：2026-10-08。

## 页面改动

- Android 首页仅展示“连接电脑、通知权限、同步通知”三张卡片。
- 电脑名称、配对令牌和可选地址改为点击“连接电脑”时填写；班级与应用包名移至“设置 → 同步范围”。
- 删除首页的回调计数、字段字数、扫描诊断、示例发送、清空队列和长篇技术说明。
- “同步一次”补收通知栏中的消息并重试待传通知；首页不会把空队列说成已收到真实消息，也不会把保存的配对说成当前在线。
- 电脑配对页收敛为安装、配对、授权三步。接收应用、浏览器正文同步与帮助默认折叠，移除模型配置、备份、提醒和无关技术说明。
- 配对信息可分别复制，令牌默认隐藏；“查看收到的消息”直接打开消息记录。
- 真正的连接失败保留简短操作提示；未知失败不会被显示成正常同步。首次尚未配置时显示设置引导。

## 尚未验证

0.2.5 尚未在用户手机覆盖安装。此次没有 Android 模拟器或真机界面截图，APK 构建和 JVM 测试不代表原生页面运行验收。升级后配置保留、权限页面、原生布局、实际通知采集、校园网发现和 IP 变化恢复仍需手机实测。学习通只向系统提供摘要时，改版不会恢复应用内正文。

覆盖安装保留原包名和签名；未改动通知队列、配对身份存储和自动发现协议。不卸载旧应用可保留原应用私有数据。
