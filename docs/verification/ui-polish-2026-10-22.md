# 系统网页视觉优化（2026-10-22）

沿用既有绿色主色和简化后的操作结构，调整今日概览、待办任务、消息收件箱、截止日历、学习通同步、手机连接、识别评测及公共弹窗。

## 改动

- 统一浅灰画布、白色卡片、边框、圆角与轻量阴影；侧栏使用统一线条SVG图标，深绿色强调当前页面。
- 首页草稿提示使用深绿色背景，主要操作突出；统计卡片统一数字、状态图标和提示层次。
- 提高小字与辅助文字的可读性，统一按钮、表单、标签、警示、原文区域与弹窗。
- 同步页状态与任务核对内容分区，统一两张卡片宽度并补齐间距。
- 手机导航保持所有入口可见；修复768px宽度日历工具栏的横向溢出。动画遵循系统减少动态效果偏好。

仅修改网页展示文件 `web/index.html`、`web/style.css`、`web/evaluation.css` 和首页一处展示文字。没有改动后端任务识别、来源记录、确认或同步逻辑。
