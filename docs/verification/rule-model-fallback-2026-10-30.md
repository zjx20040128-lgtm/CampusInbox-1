# 规则提取、模型补漏、原文校验（2026-10-30）

## 本次调整

- Agent 规则解析抛异常时，有配置模型则转模型处理；空延期候选不再直接跳过模型。
- 学习通通知解析异常后保留原文并继续模型分析。新通知、聊天及任务列表文字参与模型复核；签到身份和结束时间仍需平台核验，模型不能替代。
- 作业中心已有平台字段保留，模型仅补充缺失且有原文引用的截止、提交方式和要求。
- 微信、QQ粘贴文本缺少发布时间时仍可调用模型；采用中性解析基准，并禁止由此猜测年份或相对日期。
- 微信、QQ重复文本在模型调用前查重，处理记录保存实际请求与失败回退状态。
- QQ Connector 解析入口经过 Agent，避免规则抛异常后直接跳过模型。

## 保留边界

- 显式“仅规则”、未配置模型、网络或模型服务不可用，不保证模型成功返回；失败不自动确认任务。
- 日期必须匹配原文引用，且属于当前任务的截止；发布时间、实验安排日期不冒充提交截止。
- 附件未读取、签到身份或平台权限缺失，不能靠模型猜测补齐。
- 旧消息不自动重跑；当前后端需要重新启动才能加载修改。
