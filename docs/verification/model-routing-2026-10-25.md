# 混合识别的严格分流、未公布截止校验与逐条错因

## 改动

- `model_routing.py` 只放行完整的字段模板：课程名称、任务/作业名称、绝对完整截止日期，以及可选提交方式。所有字段须与唯一规则候选一致；候选须可匹配、无警告、无额外要求、创建操作，任务类型须与当前正文解析一致。
- 多任务、自由正文、额外行、重复字段、相对日期、延期取消、例外条件、附件提示、任何字段不一致均继续调用 Qwen。此分流不适用于任意“看起来简单”的自然语言。混合模式保留 agent 模式标记，但 trace 明确记录 rules_verified，评测也区分跳过模型与实际模型辅助。
- 当规则日期确实来自唯一的发布时间/开始时间引用，Qwen 候选截止为空，且当前任务原文明示截止“尚未公布/另行通知/待定”等，允许清空待确认草稿的错误日期，保留前后值及原文依据。结构化平台截止字段、其他日期线索、相互矛盾的截止信息都不会被清空。已确认任务不会在分析时被修改。
- 每条评测结果及汇总增加错因：原文缺失、处理错误、漏报、误报、截止错误、误填截止、操作错误、模型回退、达到上限。仅统计实际匹配到的任务是否字段错误，漏报不会被重复标成该任务的截止/操作错误。保留原始准确率、召回率及截止正确率指标。
- 评测明细增加“处理方式”列及错因文字；报告导出保留这些字段。历史报告未记录错因时不伪造补填。
