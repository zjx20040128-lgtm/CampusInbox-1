# 课务助手组合查询扩展

原规则只识别状态和单个月份。本轮新增独立查询条件解析，并对同一范围快照逐项取交集：

- 截止日期：今天、明天、后天、昨天，本周/上周/下周/周末，未来N天，月份、具体日期、连续日期区间和具体日期之前/之后。周一为每周起点；未来N天包括今天；之前/之后按包含当天处理，回答显示实际日期边界。只有日期的截止不补造时刻。
- 课程与任务：问题内完整课程名、唯一匹配的课程简称、明确“课程：…”、任务全名、引号关键词，以及“任务名什么时候交”。关键词按课程与任务名称匹配，引用关键词中的月份不当成截止月份。
- 提交状态、无截止任务、任务类型、数量查询和截止排序可与上述条件组合；课程/班级输入框始终限定服务器范围，不因问题中的课程放宽。
- 无效日期、歧义简称、冲突时间条件明确返回错误；规则模式中的未识别条件返回提示，不忽略条件后输出全量结果。按具体时分筛选及任意开放问答不在本轮支持范围。

沿用用户口径：默认“尚未提交”排除已提交、取消和逾期；具体任务名/关键词查询默认查询全部状态并标注结果状态。普通列表默认截止升序，无截止排后，最多展示10条并保留总数。数量问题只显示总数。本轮不修改任务进度、不推断平台提交状态。

界面新增默认折叠的四个查询示例，点击仅填入问题，不自动提交。规则回答不再显示0次工具轨迹。

验证：26项助手查询专项（其中3项真实隔离HTTP）、原Agent7项、核心44项全部通过。覆盖日期和跨年边界、范围组合、已提交/逾期排除、未知截止、关键词、任务类型、课程简称歧义、模型不覆盖确定性筛选、范围不能扩大、HTTP查询前后五张业务表不变。

已备份并重启正式服务，五张业务表逐项一致，恢复原同步与手机提醒设置。正式浏览器实际查询周、月、课程、关键词、无截止、数量和任务名七组结果，与独立筛选逐项一致；示例只填入，无业务写请求；1280/390px无弹窗溢出或页面错误。部署、截图和只读核对结果见artifacts/assistant-query-20261023/。
