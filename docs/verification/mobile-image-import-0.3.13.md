# Android 0.3.13 手机图片文字识别

用户要求手机直接选择一张图片，在本机识别文字并生成待确认任务草稿。0.3.13 在“全部消息”加入“识别图片”：系统文件选择器读取单张 PNG/JPG/BMP/WebP，限制 8 MB 并按尺寸采样；随 APK 打包的 ML Kit 中文模型执行 OCR，不依赖电脑或首次运行时下载模型。OCR 为空时仍可对照原图手动补录，识别文字、课程和消息原发布时间可在保存前修改。保存时原图片字节写入应用私有存储，消息保留文字和原图引用；识别出的任务仍是草稿，确认后才进入任务清单。手机消息详情可查看原图。

回归先观察缺失的图片导入策略测试失败，再验证 8 MB 边界、采样尺寸、OCR 原文空格、原图私有存取、重复导入和草稿状态。识别文字在校对框及消息、草稿要求中保留空格；仅任务规则使用独立的规范化副本，且不会把相邻的两个数字并成一个。独立审查发现人工课程被正文书名覆盖、编辑空格被改写，以及旋转、保存中的重复导入风险；现已修复并冻结保存中的表单，恢复时按稳定导入键核对是否已写入。`android/run-tests.ps1` 通过，包含图片导入 24 项断言及通知连接边界 20 项断言。Android Activity 的连续旋转和保存中操作仍须真机验收。

`scripts/build-android.ps1` 离线构建成功。APK 包名 `cn.courseinbox.companion`、versionCode 21、versionName 0.3.13、minSdk 26、targetSdk 35；v2 签名证书 SHA-256 为 `9320aa55a9957826a0bd4df0263f72e03730d35f9bcaf9ad794d562406979177`，与 0.3.12 相同，可覆盖安装。包中检查到中文模型资源与 arm64-v8a、armeabi-v7a、x86、x86_64 的 OCR 原生库。安装包约 47 MB。`scripts/test-platform-check-ui.cjs` 与 `scripts/browser-check.cjs` 通过并检查新版下载入口。

当前验证仅覆盖代码、协议测试、打包资源、浏览器下载入口；尚未在 iQOO 13 上测试实际选图、中文识别、旋转恢复和覆盖安装后的手机界面。图片 OCR 只提取图片中的文字，不理解无文字图表，也不会自动读取学习通网页内或系统通知中的图片。消息原发布时间不明时，相对日期保持未知。

首次打包时旧构建脚本将 0.3.13 APK 复制到了 `0.3.12` 文件名；确认其内部版本确实是 0.3.13 且与正式 0.3.13 文件字节相同后，已删除这个误标文件。旧版 0.3.12 本地 APK 因此不再可供下载；已安装在手机上的 0.3.12 不受影响。
