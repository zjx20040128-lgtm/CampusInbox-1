# 核对通知显示明确截止时间

旧评测工作文件保存了任务列表原文，例如“目标检测编程实践；剩余319小时38分钟；未交”，核对页此前直接显示倒计时。本轮在标注读取接口增加只读展示字段，复用消息列表的截止依据；通知列表和核对区显示明确截止日期/时间。无法取得可靠日期时显示“截止未获取”，不由小时数和扫描时刻反推截止。

原始通知、工作文件及expected_tasks不改写；原始倒计时可展开“原始通知”查看。若截止来自当前已确认任务或待确认草稿，会明确标注来源，不冒充旧消息的原始截止。任务中心没有发布时间时不再将采集时间当成发布时间。人工答案仍需显式填写保存，不以提示日期自动填入标注。

验证：评测网页后端11项、评测核心12项、消息时间6项通过，既有隔离HTTP和浏览器评测流程通过。正式服务已启动加载新代码，实际样本显示2026-10-30 23:59，并标注“当前已确认任务”；缺少日期的测试作业显示“截止未获取”。1280/390px页面检查通过，原文可展开、答案未自动填入，无写请求和页面错误。核对前后标注文件哈希一致，messages/tasks/proposals/sources/history五表与备份一致。

证据位于artifacts/evaluation-deadline-20261023/。备份与启动的组合命令曾被自动审批拒绝且未执行；随后分开完成SQLite只读备份与项目现有启动入口，健康检查通过。
