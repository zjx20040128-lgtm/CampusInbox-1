## 已实现并验证的范围

- 手机本地原文、去重、任务草稿、确认、手动状态、当前北京时间及逾期显示。未提交的过期任务显示“已逾期（未提交）”，不再单独显示“待开始”；取消任务不列入日历。
- 消息原文分页，每页 100 条；定时刷新保留当前滚动位置。退出账号只清网页会话，稳定的手机收件箱命名空间保留，避免重新登录同一来源重复生成草稿。
- WebView 限官方 HTTPS 页面，拒绝 SSL 错误，禁用本地文件与内容访问，没有 addJavascriptInterface。异步 DOM 结果通过 JSON 快照返回，不读取账号密码或 Cookie 内容。
- 已渲染聊天和通知文字在该网页前台打开期间读取。群名与选中会话不一致时等待，不把迟到群标题配给另一群正文；加载中的空收件页不冒充成功。
- 授权系统通知先入应用私有持久待处理队列，原文落库成功才移除；重启后重试。单条格式错误留下原文且继续处理其他通知，写盘 IO 故障暂停写入。首页与账号显示失败、残留条数和重试入口。达到存储/队列上限会报错，不承诺无限容量或零丢失。
- 旧电脑伴侣移到“账号 → 更多：连接电脑”，保留原配对、发现与待传队列配置。正式电脑数据库与学习通会话未用于新测试。
