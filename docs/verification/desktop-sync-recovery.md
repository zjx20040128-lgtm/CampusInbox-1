# 扫码后偶发连接失败修复（2026-10-08）

## 原因与范围

收到反馈时，正式状态是 enabled=true/state=error、session_saved=true，最近成功同步时间为2026-10-08 20:01（北京时间）。旧 worker 将通知列表/详情超时和导航中断统一报告为 network/error；界面主要提供重新扫码，无法区分登录失效与临时同步失败。旧日志没有分阶段诊断，无法追溯该次具体失败请求。

隔离受控网络中断已复现这一失败模式（RED）：扫码成功后中断通知页面请求，旧代码进入error。修复保留原会话，每个页面最多3次尝试；整体失败以10/20/40/60秒间隔自动恢复官方入口。单条详情失败不再令整个登录显示失败，其他通知继续处理。明确跳回官方登录/二维码页面时才显示“需要重新扫码”。“重试连接”复用加密会话。

登录识别也覆盖官方子frame；失败通知暂缓5分钟，扫描游标轮转防止旧失败条目挡住后续正常条目。阶段和错误原因只记录固定枚举，不保存URL、Cookie、账号、通知正文或异常原始字符串。
