# 作业附件 403 修复

用户点击数字图像处理任务附件时，直接访问 `d0.cldisk.com/download/{objectid}` 返回 403。上一轮仅验证文件元数据及链接展示，未完成下载验收。

## 改动

- 下载时复用本机 DPAPI 保存的学习通登录状态，在独立无头浏览器上下文中重新检查作业身份、文件名称和对象 ID、下载限制。
- 通过学习通官方 `ueditorupload/read` 入口取得当前下载跳转，而非让用户浏览器直连无签名云盘链接。仅允许 HTTPS 学习通/云盘域名，限制跳转次数、大小和时间，禁止执行作答页脚本或提交表单。
- 本机新增需要主令牌的附件下载 API，按消息 ID 与附件序号取文件；前端携带令牌请求 Blob 下载，不在 URL 中传令牌，也不打开空白标签页。
- 下载成功后缓存原字节及校验值；读取缓存时复核 SHA-256，损坏缓存重新获取。缓存中不保存 Cookie 或临时签名 URL，不修改任务、消息或截止时间。
- BMP 取回后检查文件头及声明文件长度，拒绝 403、登录 HTML 或错误页面，避免把错误网页保存为 BMP。文件下载上限 32 MB；文字提取仍使用原限制。

## 验证证据

- `scripts/test-original-download.cjs`：官方入口、临时跳转、活的任务附件身份、限制/移除、重定向循环、非官方域、403/HTML、无效 BMP、考试入口拒绝。
- `tests/test_original_files.py`：字节缓存及损坏重取、保护消息与任务、索引和空文件校验、主令牌认证、UTF-8 文件名响应。
- `scripts/test-task-attachments-ui.cjs`：点击下载产生浏览器下载事件，携带主令牌、保留原文件名、无云盘页面跳转、失败原地提示。
- 真实账号四个文件已经由新流程取回并校验。详见 `artifacts/original-download-20261025/live-download.json`；实时页面按钮下载结果见 `live-ui.json`。

首次下载需要本机学习通登录有效、原任务仍允许下载及网络可用；已缓存文件可从本机缓存再次获取。非作业中心附件当前仍沿用原消息入口。
