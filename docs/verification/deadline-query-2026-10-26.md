# 截止日期范围查询

任务页与收件箱消息记录新增起止截止日期查询，支持单边界、含首尾整天、重置。任务范围与课程/关键词/状态组合，应用自定义范围时清除快捷日期条件，选择快捷条件时清除自定义范围。

消息查询基于现有timing.deadline（原文、明确平台字段、已关联任务或单一候选依据），按北京时间比较，不使用发布时间代替截止。过滤在分页之前完成；未明确截止的消息在指定范围时排除，重置后恢复。日期严格验证，非法日期、重复参数和倒置区间返回错误。保留消息总数标签，分页显示筛选结果数；筛选期间隐藏全量清理入口，避免误以为仅清理查询结果。

接口GET /api/messages/page新增deadline_from、deadline_to，格式YYYY-MM-DD；响应增加unfiltered_total，不修改任何原文或任务。

新增单元测试覆盖北京时间跨日、无截止、单边界、分页前过滤和日期验证；隔离浏览器覆盖任务和消息实际查询、重置、范围接口错误与窄屏。完整验证及部署证据在artifacts/deadline-query-20261026/。
