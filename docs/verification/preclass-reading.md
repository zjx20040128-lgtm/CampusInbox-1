# 课前阅读通知识别修复

日期：2026-10-08。

## 原因与行为

旧规则入口只检查作业、考试、提交等关键词，要求提取只面向提交材料。这条“提前阅读材料、准备主题研讨”的通知因此保存成功，但没有任务草稿。OCR 又将“准备”等中文词断行，并夹带消息发布时间及附件文件名。

修复会仅在分析时恢复中文软换行，识别明确的阅读、预习和讨论准备指令，保留书名与多项要求，排除请勿、暂不、无需和已完成的语句。课前任务的日期只从完成要求所在的语句提取，避免把复制的发布时间作为截止日期。“无需提交”不会取消仍需完成的阅读任务。原有作业、延期和取消流程保留。

页面及日历把“提交材料”改为“任务要求”，草稿输入框能直接显示本条通知的三项要求；模型草稿说明也覆盖阅读与准备，附件正文未提供时不得推断细则。
