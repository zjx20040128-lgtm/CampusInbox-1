# 签到截止更新的重复误报

根因：缺少课程名的签到任务不能按常规名称键自动匹配，因此签到采集通过唯一原始聊天来源绑定 target_id。确认接口已经能识别这种来源绑定，但草稿显示重新计算重复列表时没有复用同一判断，将更新对象本身误报为疑似重复，页面禁用了确认按钮。任务状态更改后，旧草稿版本也已过期；重新提取又会丢失 target_override。

修复：将来源绑定判断提取为 `_checkin_target`，页面和确认入口共用，只从疑似重复列表移除有原始聊天来源关联且名称、课程、范围一致的更新对象；其他对象仍保留。刷新签到详情草稿时重新验证唯一原任务、保留目标并采用当前版本，不允许刷新成新任务，不改写任务状态。版本过期仍拒绝直接确认。

页面实测还发现分钟输入框在未修改时间时会丢弃来源秒数。确认时对未变更的原始分钟保留原完整时间；用户修改分钟时仍采用输入值。

验证：525 项 Python 回归通过。新增测试覆盖页面重复列表、伪造聊天来源不能绕过检查、过期草稿拦截、刷新后目标和版本保留、更新后任务状态保留和不创建副本。新增浏览器测试实际点击确认变更，原任务截止变为 2026-10-20T13:42:31+08:00，保持单条任务；已有防重复页面回归通过。

运行服务备份与业务表保全结果位于 artifacts/checkin-update-20261025/deployment.json。仅处理用户指出的自然辩证法概论位置签到；另外两项已取消签到保持原状态，不自动恢复。
