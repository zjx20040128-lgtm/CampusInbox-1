# Android 0.3.19 无截止任务、消息排序与清理

2026-10-16。用户要求无明确截止的任务也列出，收件箱优先展示最近任务与消息，并在全部消息增加清理。用户明确选择按原发布时间排序；发布时间未知时使用首次接收时间，避免补读旧通知挤到顶部。

## 行为

- 无截止日期的任务继续保留为待确认或已确认任务，清单标注“截止：未明确”；日历下方新增“未明确截止”区域。不给无截止任务补造日期，也不安排截止闹钟。
- 收件箱和全部消息共享按原发布时间降序的列表；未知或无效发布时间回退到首次接收时间。同发布时间再按接收时间排序，同时间保持稳定次序。消息卡标注“发布”或“接收”，详情仍分别保留两种时间。重复同步不会更新首次接收时间来抬高旧消息。
- 首页“最近任务与消息”对有任务的消息提供核对/查看任务入口。
- “全部消息 → 清理”可勾选当前页的消息，或选择“清空全部”。第二次确认明确显示数量及删除范围。清理采用用户已经看到的消息 ID 快照；确认期间新到的消息不在清理范围内。
- 已有任务不删除、不改状态。任务引用的原文从收件箱隐藏，但仍能在任务详情查看；引用的本机原图保留。未引用的消息正文删除，无剩余来源引用的本机原图在存档成功后删除，共享图片直到最后一个引用被清理才删除。
- 已清理且无任务引用的消息保留最近 10000 个 ID 的去重标记；任务引用的隐藏原文继续参与去重，避免下一次同步立即补回。超过去重窗口的历史消息可能再次被读取。
- 写盘失败恢复列表、隐藏状态和去重记录，原图不先删除。存档已成功但原图删除失败时，明确提示“消息已清理，但部分原图删除失败”，界面重新载入实际状态。

存档从原 CIM1 兼容读取，后续写入 CIM2，在原字段后追加隐藏消息 ID 与已清理 ID。没有重置用户存档，没有向实际手机发起任何清理操作。
