# 电脑版学习通完善记录

实现日期：2026-10-16。最终回归与本地交付检查：2026-10-17。

## 本轮实现

1. **历史任务分流。** 自动读取的学习通内容，在首次接收时已过明确截止、明确结束或明确已提交的独立新任务候选进入“历史归档”，原文仍保留。旧发布时间本身不构成归档理由；无截止、仍有效的任务继续待核对。已有任务的延期、取消及更新继续进入核对流程，不自动覆盖已确认任务。可以从归档恢复并重新提取，保留操作记录。“已完成一半”“已完成的同学”等表述不按已结束处理。
2. **消息排序和清理。** 按原发布时间从新到旧排序，未知时使用接收时间。每页 50 条，支持选中本页、清理所选和清理全部。确认前固定消息快照，确认期间到达的新消息保留。已确认任务、待核对草稿及关联来源原文继续保留；无引用的消息正文删除，轻量指纹持续保留以阻止补读复现。隐藏的来源仍可补全附件，不因清理而错误报告“读取完成”。
3. **后台同步恢复和诊断。** 采集进程退出、心跳或进度停滞后限次恢复，复用本机保存的登录状态；暂停、退出和旧代次回调不会恢复已停止的采集。新增“立即重新检查”，显示来源进度、列表与详情覆盖范围、图片和附件缺口。列表读取成功不等于详情全部读取成功。关闭的详情页可重新建立，单条失败不阻塞后续通知。
4. **Windows 常驻提醒。** 主窗口和托盘提供“桌面提醒”开关，每 30 秒查询一次本机持久队列。新学习任务、待核对变更及已确认任务截止可通过托盘提示并打开本机对应来源或任务。首次已有草稿及每个课程/班级/任务类型的首次盘点建立基线，避免存量轰炸；另一个课程失败不阻断已完成盘点课程的新任务提醒。重新登录通过持久代次重建基线，普通进程恢复保留基线。成功交给 Windows 显示后才确认回执，显示失败可重试，确认失败在当前进程中避免重复显示。

精确截止按 24 小时、2 小时和到期提醒；只有日期时使用前一天、当天上午 9 点及次日上午的逾期提醒，不补造截止时刻。任务已提交或取消后停止，确认改期后按新截止安排。所有任务识别与变更仍需人工确认。

## 使用与验收边界

双击项目根目录 `start-desktop.cmd`；旧程序应先从托盘退出。关闭窗口会继续驻留托盘，退出整个软件或关机后不会投递。软件需要保持运行；Windows 勿扰、通知设置及休眠可能影响实际显示时间。

受控测试可证明队列、回执和 Windows 提示调用逻辑，不能替代真实 Windows 通知可见性、点击及实体电脑休眠恢复验收；也不能证明所有学校页面或真实账号连续多日采集完整。考试及可能进入答题/提交的页面继续由用户自行打开核对。图片、扫描附件或未适配详情会明确显示缺口，不声称已读完整。
