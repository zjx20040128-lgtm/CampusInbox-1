# 原通知补充详情（2026-10-22）

## 使用入口

消息收件箱的“查看消息详情”、任务详情、同步清单均提供“补充详情”。粘贴正文，或读取图片/TXT/DOCX/PDF后核对文字，点击“生成待确认草稿”。在收件箱确认合并/变更；字段有冲突时明确选择保留当前或采用新消息。

多个目标时需要选择任务。通知时间不明确时必须填写时间依据；相对日期使用通知时间，补充保存时间另行记录。

## 数据与确认

补充保存为独立的用户证据，原消息正文及发布时间保留。SQLite新增关联表，补充草稿同时关联原文和补充来源。确认前不会写任务，确认后复用原任务编号、来源和历史；同样的补充请求可安全重放。

人工记录显示待确认、已确认、已忽略或尚未识别任务。清单的人工补充状态单列，不覆盖自动详情读取与附件缺口。
