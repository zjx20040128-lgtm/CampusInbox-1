# 学习通任务逐项核对与定向补收

日期：2026-10-19。范围为 Windows 电脑端现有后台同步，不更新 Android APK。

## 已实现

- 采集器先报告当前可读取的课程目录和每个作业/考试栏目的预期任务，再发送实际原文及最终列表检查结果。课程、班级和任务编号不完整或不匹配时保留覆盖缺口，不按相同标题关联。
- 持久化清单以完整平台身份和实际内容版本，对照本地原文、草稿、关联任务和清理指纹，区分未保存、未识别、待确认、已关联任务、历史归档、已忽略及已清理。
- 列表版本与详情版本分开保存。未变化的列表摘要不会覆盖已取得的详情回执，也不会因预算、超时或重启而重新恢复已清理内容。独立倒计时不参与内容版本，真实要求和截止变化仍可进入确认流程。
- 仅平台提交状态变化时，按同身份、同实质内容的已有来源核对，不误当成提取失败；保留已忽略、归档或清理的决定。不会通过此功能自动改变本地任务进度。
- 自动安排缺失原文、失败的自动提取和支持的详情补读，按10/20/40/60秒退避，每次最多5项；未完成栏目每次最多2个，至少间隔60秒。定向任务/栏目优先检查，同时保留普通课程轮转和每栏目5个详情的预算。
- 网页“学习通同步”增加核对清单，每页20项，显示栏目失败、身份缺口、详情和媒体范围，可补收单项、补收缺失项或重试栏目。原生桌面窗口提供直达入口。
- 图片、音视频及嵌入内容的未读数量保留到任务级别；重新按规则提取时仍保留警告。

补收链路回归使用临时数据库：平台清单已发现但原文未交付 → 未保存 → 安排定向补收 → 相同任务重复交付 → 仅一条消息和一份草稿 → 一次提醒队列事件 → ACK 后不再投递。该验证不证明 Windows 系统通知实际显示。

本轮未清理、迁移或修改正式消息与任务数据；新增清单在后台实际扫描后生成，存放于 `data/chaoxing-sync/task-inventory.json`。退出账号或重新扫码时清单重建，暂停/普通重启后保留记录并重新核对覆盖。
