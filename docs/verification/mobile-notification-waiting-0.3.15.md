# Android 0.3.15 通知连接等待与手机端诊断

2026-10-15。用户确认 iQOO 13 覆盖安装 0.3.14 后先出现“通知接收仍未连接”，随后约 1～3 分钟连接成功。不能把这次反馈继续记成无法连接，也不能据此断言系统延迟的根因。

## 已实现

- 去掉等待 25 秒后的失败弹窗。授权有效但尚无连接回调时，显示“正在连接（已等待…秒）”；三分钟后改为“连接较慢”，依然明确尚未连接。后台重试沿用 0.3.14，不改动系统授权。
- 界面在前台观察连接状态，连接成功后自动刷新；离开应用时取消界面轮询与诊断弹窗，返回后继续观察，累计耗时不会随每次重试或打开页面重置。
- “我的 → 手机提醒 → 连接诊断”显示并可复制设备、版本、通知访问状态、当前服务阶段、上次连接耗时、重连/重建次数、最近系统异常以及最多 24 条历史事件。记录服务创建、绑定、连接、断开、解绑及销毁，不读取或复制消息正文、登录凭据或配对令牌。当前状态和历史事件分开标明，历史时间使用 UTC。
- 通知使用权入口优先打开本应用监听组件的系统设置；设备不支持时回退到通知使用权列表。应用不自动切换开关。

依据：[NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService) 要求以连接回调确认服务可用；[Settings](https://developer.android.com/reference/android/provider/Settings#ACTION_NOTIFICATION_LISTENER_DETAIL_SETTINGS) 定义组件级授权页面及其字符串组件参数。本次三分钟是界面慢连接提示阈值，依据本机用户反馈选择，不是 Android 规定的绑定时限或性能承诺。
