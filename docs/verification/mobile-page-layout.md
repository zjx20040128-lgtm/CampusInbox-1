# 常用官方页手机布局、刷新与登录状态 · 0.3.4

日期：2026-10-11。用户截图显示课程首页仍是电脑版、右侧被截断、已登录却提示先登录，并且没有独立刷新入口。用户确认将范围扩大到常用官方页面及 App 自身五个页面。

## 已实现

- 已知官方门户、独立课程列表、聊天、收到的通知列表与通知详情分别应用手机宽度、字号和排版。扫码登录与账号登录沿用既有 0.3.3 布局。
- 门户原菜单可展开，两个账号区域保持可见，保留原菜单、事件和 iframe 节点。官网使用跨域嵌入，外层样式无法改子页；对精确白名单内的课程、聊天和通知 iframe，提供“展开课程页／聊天消息／课程通知”链接，在当前视图打开原官方 URL，之后按该页适配。未知、登录及外部 iframe 不提升为链接。
- 课程卡片单列；聊天会话列表可收起；消息长文本换行；通知标题与正文可换行；正文表格局部滚动，图片与附件不越过手机宽度。
- 官方页顶部常驻“返回／刷新／说明”。刷新及布局切换先提醒未提交的登录输入或编辑内容可能丢失；确认仍属于当前 URL 和加载代次才重载。不会主动清除 Cookie 或手机存档。返回优先使用网页历史。
- 本机首页、消息、任务、日历、账号页提供“刷新手机存档”，明确只重读本地数据。原生按钮改为可换行、自适应高度，去掉默认最小宽度；文字导入表单加滚动容器。
- 门户登录通过可见账号区域及保留的课程／消息菜单结构识别，不再只依赖通知 iframe。独立课程页要求完整、可见的课程卡片；空骨架、未知地址、隐藏残留及登录/验证控件不视为已登录。门户与课程识别不采集课程记录，消息采集范围仍仅聊天与通知。
- 未识别页面显示“当前页面暂未识别”，不直接断言未登录；未知布局保留官方缩放，可以在“说明”切回官方原版。
