# 学习通通知正文诊断：0.2.4

2026-10-05 23:22 到达的真实学习通通知，在用户覆盖安装 0.2.3 后，电脑仍只收到“您有一条新消息／请点击查看”。数据库没有该消息的隐藏正文，重新提取不能恢复。新开网页可见“仅收到摘要”和“导入完整内容”；用户截图中的旧标签页需要重新载入。服务对脚本返回 `Cache-Control: no-store`。

0.2.3 在多个通知字段同时存在时固定优先取消息列表，即使那里仅有“请点击查看”。0.2.4 改为优先选择非占位文字，在同类字段中取更长的文字，并在手机界面列出普通文字、展开文字、多行文字、消息列表及最终发送文字的字数，不显示私人内容。

JVM 文本选择测试 7 项通过，Android 离线构建成功。APK 版本号 6 / 0.2.4，SHA-256：`E0432503B0F0F85A95939482E3C0E5C89E0CD0B5736A0DC16D130DF6A965F725`；签名证书 SHA-256 与 0.2.3 相同。新版本能否读到学习通应用内正文仍需用户手机收到新通知后验证。若手机“通知字段”仅显示简短文字，则完整内容需在学习通打开后复制或截图导入。
