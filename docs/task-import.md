# 统一新建任务与附件解析

已适配小组仓库 `Elias-2z/CampusInbox` 的 `1d02252df342fe4c837b386e16c4b83a5d0cd3f4` 更新。融合版继续使用现有 Python 服务、SQLite、学习通同步和任务审核流程。

## 使用

进入「我的任务 → 新建任务」，选择：

- 文本粘贴：核对通知正文、来源及实际发送时间，识别后到收件箱审核。
- 图片上传：支持 PNG、JPG、JPEG、WebP；可预览图片，经同意后由 MinerU 云端提取文字。
- 文件上传：TXT / Markdown 在本机以 UTF-8 / GB18030 读取；PDF、DOC、DOCX、PPT、PPTX 经同意后由 MinerU 云端提取。
- 手动填写：核对名称、课程、班级、类型、截止、材料及提交方式，点击创建后直接进入正式任务。

单文件最大 20 MB。解析只提取文字，不自动创建任务；可编辑提取文本，保留本次通知相关内容后提交审核，最多 20000 字，不静默截断。通知发送时间以北京时间填写，供解释“明天 / 下周”。手动任务可选择未明确截止、仅日期或精确到分钟，保留“已做完”和“已提交”的区别。

## MinerU 配置

在 [MinerU API 管理](https://mineru.net/apiManage) 创建 Token，保存到融合版根目录私有 `.env`：

```dotenv
MINERU_API_KEY=你的Token
```

也可设置同名进程环境变量，环境变量优先。`.env` 每次请求重新读取；配置后重新打开新建窗口。浏览器和设置页只显示是否配置，不返回 Token。

接入的是 MinerU 托管精准解析 v4 API。只有用户勾选同意并点击解析后才向 MinerU 发送原文件，可能消耗账户额度；TXT / Markdown 不发送。未配置 Token 时文本粘贴、手动创建和本地文本文件仍可用。原有 Windows OCR 和附件读取接口保留供完整工作区使用。

## 恢复、原文件与备份

- 可以关闭解析窗口，之后在图片或文件方式下展开「最近上传 · 继续处理」。服务重启保留已保存的解析记录和批次。
- 暂时断网后继续查询原批次，不重复提交；任务失效或明确失败后可重新解析。并发重试只提交一次，旧批次的迟到响应不能覆盖新结果。
- 原文件在当前数据库同级的 `uploads/` 目录，使用服务端 ID 命名；文件名只作展示和下载名。
- 提交审核后，消息详情和任务详情均可下载原附件；重复点击同一附件提交不会重复创建通知。
- JSON 导出不包含文件二进制。完整备份应保留数据库、`uploads/` 及需要的私有配置；完整复制整个副本也会保留这些文件。
- 未提交的上传文件保留在本机，尚未提供图形化删除功能。
